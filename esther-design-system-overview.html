02 / SCENES

CHOOSE A STARTING POINT

五种任务，各有起步模板

先按交付内容选场景，再读取对应规范和模板。点选类别查看它的设计重点。

LEARN · EXPLAIN · GUIDE

教程型 / 介绍型 / 科普型

用清楚的信息层级和不同 section 布局讲完整一件事。允许克制的滚动揭示、大字号和视觉惊喜，但不能牺牲阅读节奏。

  • 至少 3 种布局
  • clamp 流体字号
  • Scroll Reveal
起步文件把复杂知识
讲得有节奏template-tutorial.html

INVITE · PRESENT · CONVERT

活动页 / 分享会 / Landing

让页面有开场、有节奏，也有明确的下一步。常用强视觉 Hero、深浅面板交替、CTA、头像集群和流程条。

  • CTA 清楚
  • 节奏变化
  • 头像与引言组件
起步文件一眼看懂活动，
知道怎么加入template-landing.html

NAVIGATE · FILTER · ACT

App 型 / 功能型

功能优先、信息密度更高、交互反馈明确。常见骨架是固定 Header、Tab 或侧栏、内容区与卡片网格。

  • 导航常驻
  • Hover / Focus 状态
  • 移动端单列
起步文件先找到功能，
再完成操作template-app.html

3:4 · MOBILE FIRST

小红书图文卡片

画布按 1080×1440 设计，字号适合手机阅读；页与页之间更换排版手法，并提供单页 PNG 与批量导出体验。

  • 封面 / 内容页 / 尾页
  • 建议不超过 18 张
  • 导出 PNG / ZIP
起步文件一页一个重点，
翻页有节奏template-cards.html

WECHAT EDITOR

公众号杂志编号风

适配公众号编辑器：以 section 做布局容器，样式内联，正文保留原文；有标题断行与图片 base64 交付要求。

  • 677px 内容宽度
  • 18px 正文 / 2 倍行高
  • 内联样式 + base64
起步文件复制进编辑器
也保留排版感template-wechat.html

三级检查清单

P0

中性色/结构色/强调色约 60/30/10、暖纸底、标题衬线与正文无衬线、响应式、每节布局有变化、clamp 流体尺寸、无默认 HTML 样式。

P1

至少一个视觉惊喜、字号对比明显、Scroll Reveal 与 stagger、大装饰数字或英文、selection 高亮。

P2

图片出血、深色面板、装饰克制，并尊重 prefers-reduced-motion。

# Decision records

Store decisions that the user explicitly selected or confirmed and that are likely to guide future project work. Keep each record narrow and link to its evidence and current canonical project files.

Use the format in [`../templates/decision.md`](../templates/decision.md). When a decision changes, mark the earlier record `superseded` and link the replacement instead of deleting the history. Do not turn a broad aesthetic direction into unconfirmed font, color, or component rules.

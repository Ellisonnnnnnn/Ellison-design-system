## Provenance rules

- Prefer repository-relative paths so links remain useful after moving the project.
- For user-confirmed choices, say that the source is a project conversation and quote only the relevant confirmation.
- Include a date when it is known; write “date unavailable” rather than guessing.
- For externally sourced claims, record the direct URL, access date, and which claim it supports.
- Never place credentials, payment data, private chat history, or unrelated personal details in this public repository.

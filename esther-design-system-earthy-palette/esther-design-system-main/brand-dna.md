# Brand DNA — 品牌基因（自然色系修订版）

> 本版按用户提供的 4 张色彩参考图重整品牌色。色值来自图中标注的色卡与渐变；原版蓝黄红方案已替换。若用于自己的品牌，仍应替换姓名、头像、IP 与品牌信息。

## 🎨 新品牌色板

### 核心颜色

| 角色 | 名称 | 色值 | 用途 |
|------|------|------|------|
| 纸感底色 | Sweet Vanilla | `#FEF5DC` | 页面底色、留白、卡片底 |
| 主结构色 | Army Green | `#4B5320` | 品牌主色、导航、标题与主要状态 |
| 辅助冷色 | Nordic Lake | `#5FA8C2` | 插图、图表、局部面板；小字需提高对比 |
| 正文墨色 | Coffee | `#572013` | 正文、标题、深色文字 |
| 暖强调色 | Clay Orange | `#CF5527` | 重要提示、短标签、少量 CTA |
| 深强调色 | Wine Red | `#7D2027` | 深色强调、重要节点、少量按钮 |

### 辅助颜色

| 角色 | 色值 | 建议用途 |
|------|------|----------|
| Oat / 浅燕麦 | `#FAE3B1` | 暖色分区与柔和卡片底 |
| Pale Gold / 浅麦黄 | `#FEEDA7` | 荧光笔、高亮底、选择状态 |
| Olive Gold / 橄榄金 | `#998731` | 小面积装饰、图表次级标记 |
| Terracotta Brown | `#673C34` | 次级文字、木质与皮革感面板 |
| Chestnut | `#63493E` | 次级文字与暖灰层级 |
| Brick rust | `#911A1D` | 强烈警示或深红装饰，少量使用 |
| Limestone | `#EEEBE6` | 石灰岩中性底色 |
| Nordic Mist | `#C5D1D8` | 冷灰蓝背景与分区 |
| Powder Blue | `#D3E6F7` | 浅蓝卡片底、信息提示底 |

### 面积与组合原则

- **60% 纸感中性色**：优先 `#FEF5DC`，按内容可搭配 `#FAE3B1`、`#FEEDA7` 或 `#EEEBE6`。
- **30% 结构色**：每页挑 1–2 个主结构色，例如 Army Green `#4B5320`、Nordic Lake `#5FA8C2`、Coffee `#572013`。
- **10% 强调色**：从 Clay Orange `#CF5527`、Wine Red `#7D2027`、Olive Gold `#998731` 中选 1 个主强调，其他强调色只点到为止。
- 比例是视觉面积的参考，不是每个色值都必须出现。一个页面避免把整张色卡同时铺满。
- 保留暖纸底；页面文字使用深色墨色。浅蓝与橙色适合做面板或大字点缀，不用作奶油底上的小字号正文。

### CSS 变量命名

按色彩角色命名，避免把颜色绑死在某个组件上：`--paper: #FEF5DC`、`--olive: #4B5320`、`--lake: #5FA8C2`、`--ink: #572013`、`--rust: #CF5527`、`--wine: #7D2027`。辅助色使用 `--sand-warm`、`--sand`、`--antique`、`--earth`、`--chestnut`、`--brick`、`--stone`、`--mist`、`--powder-blue`；渐变只使用本规范列出的三组配方。

### 对比度提示

在 `#FEF5DC` 上，`#572013`、`#4B5320`、`#673C34`、`#7D2027` 适合作为正文或标题。`#CF5527` 适合较大字号与强调；`#5FA8C2`、`#998731`、`#C5D1D8`、`#D3E6F7` 优先作为装饰、图形或背景色，避免承担小字号正文。

## 🌈 品牌渐变配方

以下三组渐变直接来自参考图，可在 Hero、全宽面板、封面或插图背景中择一使用。渐变本身已经有足够表现力，周边装饰应减量。

| 名称 | 色阶 | CSS |
|------|------|-----|
| Forest Green | `#323D2E` → `#9AA48C` → `#BCC7BE` | `linear-gradient(135deg, #323D2E, #9AA48C, #BCC7BE)` |
| Sahara | `#59361E` → `#EDBA8D` → `#F7F7F7` | `linear-gradient(180deg, #59361E, #EDBA8D, #F7F7F7)` |
| Sea | `#096060` → `#075057` → `#D2ECF2` | `linear-gradient(180deg, #096060, #075057, #D2ECF2)` |

禁止蓝紫渐变、霓虹渐变和没有对应场景的多色渐变；上面三组是品牌指定的例外配方。

## 🔤 字体基因

- 中文标题使用 `Noto Serif SC`，选择中高字重，形成清晰、精致的标题轮廓。
- 英文标题、系列名和大号编号使用 `Bodoni Moda`；斜体只用于短副题或少量英文点题。
- 中文正文与 UI 使用 `Noto Sans SC` 和系统无衬线栈，保证阅读清楚。
- 代码只在终端场景使用 `Fira Code`。手写字体不属于默认品牌字体；组件库里的手写样式仅在内容确实需要时单独挑选。
- CSS 字体变量：`--font-serif: "Noto Serif SC", "Songti SC", serif`；`--font-display: "Bodoni Moda", Georgia, serif`；`--font-sans: "Noto Sans SC", -apple-system, "PingFang SC", sans-serif`。
- Hero 大标题：`clamp(2.8rem, 7vw, 5.5rem)`；Section 标题：`clamp(1.6rem, 4vw, 2.6rem)`；正文基准 16px。
- 标题与正文形成鲜明字号对比。不要用 Inter、Roboto、Arial 等常见默认字体替代品牌字体搭配。

## ✨ 气质关键词

时装画册式编辑感；成熟、利落、有张力，但不冷硬。保留纸张、木质、矿物与湖水的自然材质线索，用大色块、裁切构图和精致留白呈现新色板。标题有存在感，内容层级清楚；避免做成可爱手帐、蜡笔涂鸦或通用 AI 模板。

## 🚫 通用禁忌

| 类型 | 禁止或限制 |
|------|------------|
| 颜色 | 蓝紫渐变、neon、无关的多色渐变；纯黑与刺眼纯白作为大面积底色；小字号浅色文字 |
| 布局 | 所有 section 居中、千篇一律卡片网格、cards 嵌套 cards |
| 动效 | bounce / elastic、动画化 width / height、无意义无限循环 |
| 装饰 | glassmorphism、廉价光效、无意义 stock photo、过度滤镜、装饰堆砌、默认手写涂鸦 |
| 引用 | 浏览器默认 blockquote 与无样式列表；不要把 border-left 竖条当作通用引用组件 |
| 排版 | 行距或字距出现明显异常；英文专有词被断开；移动端隐藏正文内容 |

## 📐 间距与响应式

- Section 之间：`clamp(80px, 12vh, 160px)`。
- 内容块之间：`clamp(40px, 6vw, 100px)`。
- 卡片内边距：`clamp(28px, 3vw, 44px)`。
- 内容最大宽度约 1300px，按场景可收窄。
- 900px：两栏转单栏、sticky 侧栏转普通流；600px：字号微缩并进一步收紧布局。
- 移动端通过重排适配，不隐藏重要内容；遵守 `prefers-reduced-motion`。

## 🔍 细节

- 选中文本高亮使用浅麦黄 `#FEEDA7`，文字保持 Coffee `#572013`。
- 链接悬停用浅色底块或下划线，不依赖颜色变化。
- 主色、背景色与文字色按角色命名；新增色需同步更新所有模板和示例中的 CSS 变量。

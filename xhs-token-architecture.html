01 / WHY TOKENS

Token，是给设计决定起名字

#2563EB 本身只是一个蓝色值。给它命名后，系统就能理解：它代表什么、在哪里复用。

02 / PRIMITIVE

Primitive：最基础的原材料

它只描述数值，不替数值决定用途。

RAW VALUES
--blue-600: #2563eb;
--blue-500: #3b82f6;
--gray-100: #f3f4f6;
--gray-50: #f9fafb;
--gray-200: #e5e7eb;
--gray-600: #4b5563;
--gray-900: #111827;
--blue-700: #1d4ed8;
--white: #ffffff;

--spacing-1: 4px;
--spacing-2: 8px;
--radius-md: 8px;
这个蓝色
具体是什么？
间距是多少？
圆角是多少？

它不回答：这个蓝是按钮色还是链接色？这个灰是页面底还是卡片底？

03 / SEMANTIC

Semantic：把数值翻译成产品语言

语义 Token 描述“它代表什么”。同一种角色可以映射到不同的原始值。

品牌主色
--color-brand-primary← --blue-600
主要文字
--color-text-primary← --gray-900
次要文字
--color-text-secondary← --gray-600
页面背景
--color-bg-page← #ffffff
卡片背景
--color-bg-card← --gray-50
默认边框
--color-border-default← --gray-200
组件只需要知道：color: var(--color-brand-primary);
不用知道它底下映射的是 blue-600 还是 blue-500。

05 / COMPONENT TOKENS

Component Token：Button 的专属规格

它把通用语义收束成某个组件的具体用法。

BUTTON / PRIMARY HOVER STATE
BUTTON TOKENS
--button-primary-bg:
  var(--color-brand-primary);
--button-primary-text: var(--white);
--button-primary-bg-hover:
  var(--color-brand-primary-hover);
--button-radius: var(--radius-md);
--button-height-md: 40px;
COMPONENT CSS
.button-primary {
  background: var(--button-primary-bg);
  color: var(--button-primary-text);
  border-radius: var(--button-radius);
}
.button-primary:hover {
  background: var(--button-primary-bg-hover);
}

06 / COMPONENT TOKENS

Input，也有自己的状态语言

输入框沿用页面语义，但边框、焦点等细节由 Input Token 管理。

DEFAULT FOCUS
INPUT TOKENS
--input-bg:
  var(--color-bg-page);
--input-border:
  var(--color-border-default);
--input-border-focus:
  var(--color-brand-primary);
--input-text:
  var(--color-text-primary);
INPUT CSS
.input {
  background: var(--input-bg);
  border: 1px solid var(--input-border);
  color: var(--input-text);
}
.input:focus {
  border-color: var(--input-border-focus);
}
同一产品语义，到了 Input 组件里，才变成边框、焦点和文字的具体规格。

08 / AVOID THE BLAST RADIUS

别把 Primitive 直接写进组件

今天看起来省一步，改色时可能牵一串。

✕ 直接写死
.button {
  background: var(--blue-600);
}
你不知道这个蓝还被多少地方共用。
✓ 使用组件 Token
.button {
  background: var(--button-primary-bg);
}
调整按钮规格，不影响其他组件。
按钮链接标签图表选中状态AI 高亮
